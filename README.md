# Python 图书管理系统

一个用 Python 实现的命令行课程练习。代码以 `Book` 表示单本图书，`BookManager` 负责菜单、图书管理和 JSON 保存。

## 运行

需要 Python 3.10 或更新版本。项目使用 Python 标准库。打开仓库目录后运行：

```powershell
python library_manager.py
```

## 操作示例

- 输入 `6`，查看第 `1` 页和第 `2` 页。仓库提供六条虚构样例，每页最多显示五条。
- 输入 `4`，按 `DEMO-001` 查找样例图书。
- 使用菜单录入、修改或扣减库存后，输入 `5` 保存。退出并重新运行，程序会读取保存过的记录。

`book_datas/books.json` 是启动数据，也是菜单保存时更新的文件。图书编号作为字典键。录入同一个编号会覆盖原条目，数量和价格请按提示输入有效数字。
